## Projects

### Audio Deepfake Phylogeny (in progress)
Unsupervised forensic framework that models speech generators as a family tree in hyperbolic (Poincaré) space. Aims at ancestry attribution, open-set detection of new generator families, and copy-synthesis detection across frame, segment and utterance scales.
*PyTorch, geoopt, self-supervised hyperbolic contrastive learning*
[Code](LINK)

### Domain Drift in Audio Spoof Detection
Distribution-shift study between ASVspoof 2019 LA and In-the-Wild deepfake data, plus continual-learning experiments that fine-tune wav2vec 2.0 sequentially across three data distributions and track per-sample drift with Mahalanobis distance.
*PyTorch, wav2vec 2.0, continual learning*
[Code](LINK)

### JoyCore: On-Device Agentic AI for Android
Fully offline agent on Android: a small orchestrator LLM (Gemma 3 1B / Qwen2.5 / SmolLM2) routes tasks to specialised models for speech recognition (Whisper), translation (NLLB / OPUS-MT), vision (MobileVLM / PaliGemma) and object detection (YOLO).
*LiteRT-LM, on-device inference*
[Code](LINK)

### LLM Extension for Znuny Ticketing (University of Stuttgart TIK)
LLM-powered German–English translation and ticket summarisation inside the university's Znuny ticketing system; in production for university agents and admin staff.
*LLMs, Znuny / OTRS, production deployment*

### Synthetic Data Generation with Multimodal LLMs
Image-labelling pipeline using vision-language models (Qwen 2.5-VL, Granite 3.2-Vision) to generate synthetic training data.
*VLMs, data pipelines*
[Code](LINK)

### SciWalK: Thermal Environment Tracker (IABP Lab)
Raspberry Pi system measuring thermal comfort (UTCI), with a role-based Flask dashboard (Operator / Developer / Guest) and STM32-based sensor firmware for field testing.
*Flask, Raspberry Pi, STM32, IoT*
[Code](LINK)

### Agentic Job Application System
Self-built agent that automates parts of the job-application workflow.
*LangGraph, Playwright*
